# Signal template direction

This branch implements a reusable private-instance template. Its canonical setup guide is [setup.md](setup.md).

The earlier shared-service proposal is superseded here: each installer owns their deployment, database, Access policy, and optional OpenAI project. This branch has no public signup, shared key, credits, or payments.

Release from a sanitized source snapshot into a new repository. Do not publish the development repository's inherited history.
